**XC Meet Manager is now a proper Windows app, and it keeps your meets in sync between computers through OneDrive.**

### Install
Download **`XC Meet Manager_x.y.z_x64-setup.exe`** below and run it. It installs for the current user only, so no admin rights are needed.
The installer isn't code-signed yet, so Windows may show *"Windows protected your PC"*. Click **More info → Run anyway**.

### Sync between computers
- When the app first opens, it offers to sync through OneDrive (`OneDrive\XC Meet Manager`). Turn it on with the same folder on each computer.
- No internet at an event? Keep working as normal. Changes go across once the laptop is back online and the app is opened.
- If the same meet is changed on both computers before they sync, nothing is lost. The later version is kept as normal, and the earlier one is kept too, marked **kept copy**.
- The ☁ button at the top shows the sync status. Click it for details or to sync now.

### Coming from the earlier (browser) version?
Your meets don't move across by themselves:
1. Open the old version (the `.bat` launcher) → **Meets** → **Back up all meets**.
2. Open the new app → **Meets** → **Import meet file…** → choose that backup.

Do this on one computer only. Sync then brings everything to the other one.
