### Install
Download **XC-Organiser-setup.exe** above and run it. It installs for the current user only, so no admin rights are needed.
The installer isn't code-signed yet, so Windows may show *"Windows protected your PC"*. Click **More info → Run anyway**.

### Updates
The app checks for new versions by itself and downloads them in the background. When one is ready, an orange **↺ Restart to update** button appears at the top. Click it and the app closes for a few seconds, then reopens on the new version. You can also check yourself at the bottom of the **Meets** screen.

### Sync between computers
- When the app first opens, it offers to sync through OneDrive (`OneDrive\XC Organiser`). Turn it on with the same folder on each computer.
- No internet at an event? Keep working as normal. Changes go across once the laptop is back online and the app is opened.
- If the same meet is changed on both computers before they sync, nothing is lost. The later version is kept as normal, and the earlier one is kept too, marked **kept copy**.
- The ☁ button at the top shows the sync status. Click it for details or to sync now.

### Coming from the browser version?
In the old version, use **Meets → Back up all meets**. Then in the app, use **Meets → Import meet file…**. Do this on one computer only, and sync brings everything to the other.
